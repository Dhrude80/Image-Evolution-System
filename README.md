# Image-Evolution-System

A Python project that simulates random image evolution using NumPy arrays and stochastic transformations.

The program repeatedly applies random modifications to regions of an image, causing the image to gradually evolve over time.

---

## Features

- Random region selection
- Multiple image transformations:
  - Grayscale conversion
  - Color inversion
  - Brightness increase
  - Brightness decrease
  - Random noise mutation
- NumPy-based image manipulation

---

## Technologies Used

- Python
- NumPy
- Pillow (PIL)
- Matplotlib

---
